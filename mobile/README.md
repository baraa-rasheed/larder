# Larder

Expo SDK 58 app. Native tabs are the system tab bar (`expo-router/native-tabs`).

```bash
npm install
npx expo start
```

SDK 58 needs a development build. Expo Go for this SDK was not on the stores yet as of the October 15, 2026 release.

`npx expo start --web` runs the same app in a browser. The browser cannot draw UITabBar, so web uses a bottom tab bar over the same five screens.
